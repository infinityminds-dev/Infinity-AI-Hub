# Contributing to Infinity AI Hub

Thank you for your interest in contributing to **Infinity AI Hub**! 🧠🤝

Infinity AI Hub is a Python-based self-learning conversational AI project focused on experimentation, persistent memory, AI engines, and practical development.

We welcome useful ideas, bug reports, improvements, and code contributions.

---

## 🚀 Ways to Contribute

You can contribute by:

- 🐛 Reporting bugs
- 💡 Suggesting new features
- 🧠 Improving AI engine behavior
- ⚡ Improving performance
- 🔐 Improving security
- 📚 Improving documentation
- 🧹 Improving code quality
- 🧪 Testing new features
- 🔀 Submitting pull requests

---

## 🐛 Reporting Bugs

Before reporting a bug, please check whether the issue has already been reported.

When creating a bug report, include:

- A clear description of the problem
- Steps to reproduce the problem
- The affected version
- Your Python version
- Your operating system
- Relevant error messages or logs
- Screenshots when useful

Please avoid posting passwords, API keys, private information, or other sensitive data.

---

## 💡 Feature Requests

Feature suggestions are welcome.

When suggesting a feature, please explain:

- What the feature does
- Why it would be useful
- How it could improve Infinity AI Hub
- Any implementation ideas you may have

---

## 🔀 Pull Requests

Before submitting a pull request:

1. Make sure your changes are related to the purpose of the project.
2. Test your changes locally.
3. Make sure existing functionality still works.
4. Keep the changes focused and understandable.
5. Update documentation when necessary.
6. Do not include passwords, API keys, tokens, or private information.
7. Provide a clear description of what your pull request changes.

---

## 🧪 Testing

Please test your changes before submitting a pull request.

For changes involving the Web Hub, test:

- Flask startup
- Model switching
- Memory selection
- JSON creation
- Chat functionality
- Mathematical queries
- File handling where applicable

For changes involving the AI engines, test the affected engine and make sure existing memory and response functionality continues to work.

---

## 🧠 AI Engine Contributions

Infinity AI Hub currently contains two main AI engines:

- **v7.0 Neural Engine** — `main_engine.py`
- **v5.6 Legacy Engine** — `v5_6_AI_engine.py`

Changes to either engine should be tested carefully because they may affect:

- Intent classification
- Memory handling
- Training
- Chat responses
- Mathematical processing
- Session behavior

---

## 🔐 Security

If you discover a potential security vulnerability, please **do not publicly disclose sensitive security details in a GitHub Issue or pull request**.

Instead, follow the instructions in [`SECURITY.md`](SECURITY.md).

Security-related contributions and improvements are welcome.
