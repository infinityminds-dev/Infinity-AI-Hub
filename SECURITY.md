# Security Policy

## Supported Versions

The following versions of Infinity AI Hub are currently supported with security updates:

| Version | Supported |
| :------ | :-------- |
| v7.x    | :white_check_mark: |
| v5.6.x  | :white_check_mark: |
| < v5.6  | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in Infinity AI Hub, please report it privately.

Please do **not** create a public GitHub Issue for security vulnerabilities.

You can report a vulnerability through the repository's **Security** tab using GitHub's private vulnerability reporting features, if available.

When reporting a vulnerability, please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected version
- The potential impact
- Any relevant logs or screenshots
- A possible fix or mitigation, if known

## Response

We will review valid security reports and investigate the issue.

If the vulnerability is confirmed, we will work on a fix and release an appropriate update when possible.

Please allow reasonable time for investigation and remediation before publicly disclosing the vulnerability.

## Security Scope

Security reports are especially welcome for issues involving:

- Remote code execution
- Unauthorized access
- Sensitive data exposure
- Malicious file handling
- Unsafe input processing
- Dependency vulnerabilities
- Web Hub security issues
- Other vulnerabilities that could affect users of Infinity AI Hub

Thank you for helping keep Infinity AI Hub secure. 🛡️
